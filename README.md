# Student Social Media and Mental Health Impact

## 📌 Project Overview

This project analyzes the relationship between **social media usage, student lifestyle habits, academic activity, and mental health**.

The project uses Python for data cleaning and exploratory analysis, and **Tableau for interactive data visualization and dashboard development**.

The analysis examines factors such as social media platform usage, daily usage hours, daily unlocks, purpose of social media use, study hours, physical activity, sleep, academic level, gender, age, stress, and mental health scores.

---

## 🎯 Project Objectives

- Clean and prepare the student social media dataset.
- Identify duplicate and missing records.
- Explore social media usage patterns.
- Analyze differences across platforms and student groups.
- Examine relationships between social media usage and study, sleep, and physical activity.
- Explore mental health and stress-related measures.
- Prepare a clean dataset for Tableau.
- Build interactive Tableau dashboards to communicate the findings.
